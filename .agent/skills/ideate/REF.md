## Elicitation Domains & Questions

| Domain | Questions |
|--------|-----------|
| Vision | Problem? Why now? What if we don't? |
| Users | Primary user? Secondary? Tech comfort? |
| Functional | Top 3 features? Main journey? Data? Integrations? |
| Non-Func | Load? Uptime? Security/compliance? Performance? |
| Constraints | Timeline? Budget? Tech stack? Team? |
| Risks | Failure causes? Unknowns? Dependencies? |
| Success | Metrics? MVP vs full? Definition of done? |

## Question Depth
- **quick**: 2-3/domain
- **standard**: 4-6/domain  
- **deep**: 8-12/domain

## Review Checklist
All domains covered, no conflicts, metrics defined, risks mitigated, scope clear, dependencies mapped, assumptions documented
