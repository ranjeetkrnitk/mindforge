# discover

> Open exploration to clarify vision and scope.

## Steps

1. **Greet** with project name if known, else ask
2. **Explore** (one at a time via `ask_user`):
   - What problem are you solving?
   - Why now?
   - Who benefits most?
   - Success in 6 months?
3. **Probe** based on answer type:
   - Vague → "Give a specific example?"
   - Technical → "User impact?"
   - User-focused → "Technical challenge?"
4. **Summarize** vision (3-4 bullets)
5. **List** 2-3 assumptions to validate

## Output

Vision, Problem, Opportunity, Users, Success Vision, Assumptions
End with "Next: run elicit"

## Rules
- One question at a time
- Listen > suggest
- Capture exact user language
