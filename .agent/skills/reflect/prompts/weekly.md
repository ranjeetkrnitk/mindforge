# weekly

> Last 7 days with CLS consolidation and emotion tracking.

## Steps
1. **Date range**: today - 7 days
2. **Scan** per REF.md vault scan procedure
3. **Filter** notes created in range; load all for link graph
4. **Compute** per REF.md: graph metrics, CLS signals, emotion analysis
5. **Detect** burst topics (3+ notes on same topic this week)
